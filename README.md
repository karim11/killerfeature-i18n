# 🛠 How to Contribute

We value accuracy and localization quality. To contribute:

1. **Fork** this repository.
2. **Locate** the JSON file for your language inside the `locales/` directory.
3. **New Language?** If your language does not exist, copy `en.json` and rename it.
4. **Edit** or improve translations carefully.
5. **Validate:** Ensure JSON formatting remains valid.
6. **Submit** a Pull Request with a clear description of your changes.

## ⚠️ Important Rules

* **Do not** change translation keys (e.g. `"home.title"`).
* **Do not** break JSON formatting (check commas and brackets).
* **Avoid** raw machine translations without manual review.
* **Consistency:** Keep gaming and UI terminology consistent.
* **Context:** Respect the original context of the interface.
