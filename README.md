# KillerFeature i18n

Community translations for the KillerFeature gaming ecosystem.

KillerFeature transforms your PC into a console-like gaming experience by bringing together games, emulators, media and community features into one unified platform.

This repository contains the official translation files used by KillerFeature and allows the community to help improve localization for players around the world.

## How to Contribute

1. Fork the repository
2. Edit or improve translation files
3. Keep formatting and keys unchanged
4. Submit a pull request

Please avoid:

* Changing translation keys
* Breaking JSON formatting
* Using machine translations without review

---

## Translation Files

Example structure:

```json
{
  "home.title": "Welcome",
  "library.games": "Games Library"
}
```
